# MYD — Manage Your Day

MYD es una aplicación para organizar tu día y tomar mejores decisiones con tu
tiempo y tu dinero. Reúne tareas, notas, finanzas personales, presupuestos,
metas de ahorro y reportes en un mismo lugar.

Esta versión corresponde a la **Beta**. Puedes usarla desde la web o instalar
el APK directamente en un dispositivo Android.

## Probar MYD

### Opción 1: versión web

Abre [MYD en GitHub Pages](https://estiveng1.github.io/ManajeYourDay/) desde el
navegador. No necesitas instalar nada.

### Opción 2: instalar el APK en Android

**[Descargar MYD para Android](https://estiveng1.github.io/ManajeYourDay/descargar/)**

La página oficial muestra la versión firmada más reciente. Si todavía no hay
un APK disponible, vuelve a intentarlo más tarde.

Para configurar una nueva publicación firmada, consulta la
[guía de publicación para Android](docs/android-release.md).

1. Descarga el archivo desde el enlace oficial.
2. Abre el archivo en tu teléfono Android.
3. Si Android lo solicita, permite temporalmente la instalación desde esa
   fuente.
4. Confirma la instalación y abre **MYD**.
5. Regístrate o inicia sesión.

Descarga el APK únicamente desde el enlace oficial del proyecto. No compartas
contraseñas, códigos de verificación ni datos de pago con terceros.

## Qué puedes hacer

- **Tareas:** crear tareas, prioridades, fechas, recordatorios y repeticiones.
- **Notas:** organizar notas, fijarlas y elegir vista de cuadrícula, lista o
  compacta.
- **Finanzas:** registrar ingresos y gastos, presupuestos, recibos, ubicación
  opcional y movimientos recurrentes.
- **Metas:** crear metas de ahorro, registrar aportes y consultar el progreso.
- **Reportes:** revisar periodos diarios, semanales y mensuales.
- **Exportaciones:** CSV para todos; Excel desde Estándar; PDF desde Premium.
- **Cuenta:** iniciar sesión con correo o Google, personalizar el perfil,
  idioma, moneda, tema, contraste y notificaciones.
- **Privacidad:** solicitar la eliminación de la cuenta y sus datos desde la
  aplicación.

## Planes y pagos

MYD muestra los planes disponibles dentro de la aplicación. Cuando el checkout
está habilitado, el pago se realiza en Mercado Pago: eliges un plan, continúas
al sitio oficial de Mercado Pago, completas el pago allí y vuelves a MYD.

MYD no solicita números de tarjeta, vencimiento ni CVV dentro de la aplicación.
La disponibilidad de planes y cobros puede cambiar durante la Beta.

## Permisos

Algunas funciones son opcionales y solicitan permiso solo cuando las usas:

- Ubicación, para asociar una ubicación a un movimiento financiero.
- Cámara o galería, para adjuntar un recibo o cambiar imágenes del perfil.
- Notificaciones, para recordatorios y alertas.
- Micrófono o reconocimiento de voz, según las funciones disponibles en el
  dispositivo.

Puedes administrar estos permisos desde los ajustes del teléfono.

## Estado de la Beta

La Beta puede contener cambios, límites o interrupciones mientras se validan
las funciones. Si encuentras un problema, incluye el dispositivo, la versión
de Android o navegador y los pasos para reproducirlo; nunca incluyas
contraseñas, tokens ni datos completos de tarjetas.
