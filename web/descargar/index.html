Cómo instalar
  1. Descarga el APK desde este botón.
  2. Abre el archivo descargado. Si Android lo solicita, permite temporalmente instalar desde la aplicación que lo descargó.
  3. Confirma la instalación. Para futuras actualizaciones, instala el APK oficial más reciente.

Ayuda según la marca de tu teléfono

Selecciona tu marca para ver los pasos. Los nombres de los menús pueden variar según la versión de Android.

Huawei / Honor: Play Protect bloqueó la instalación
  1. Confirma que descargaste MYD desde esta página oficial y no desde un enlace reenviado o un sitio de terceros.
  2. Si Android solo solicita permiso para instalar desde el navegador o Archivos, habilita “Permitir desde esta fuente” para esa aplicación durante la instalación y desactívalo después.

Si Play Protect dice que la app es dañina o bloquea explícitamente su instalación, no desactives Play Protect ni fuerces la instalación. Cancela, verifica que Play Protect esté actualizado y vuelve a analizar el teléfono. Si el bloqueo continúa, contáctanos desde el centro de ayuda de MYD.

Redmi / Xiaomi / POCO: conflicto con el paquete

Este mensaje suele aparecer cuando ya hay una copia de MYD instalada con otra firma, por ejemplo una versión de prueba instalada desde Flutter. Android no permite actualizar esa copia directamente con el APK firmado de publicación.

  1. Antes de quitar la copia anterior, confirma que puedes iniciar sesión y que tus datos están sincronizados con tu cuenta. Desinstalar puede borrar ajustes guardados solo en ese teléfono.
  2. En Ajustes > Aplicaciones > Administrar aplicaciones, busca MYD y desinstala la copia anterior.
  3. Si usas Aplicaciones duales o Segundo espacio, revisa también allí y elimina la copia anterior de MYD.
  4. Descarga de nuevo el APK desde esta página y vuelve a instalarlo.

Si sigue apareciendo el conflicto, no borres otras aplicaciones: reinicia el teléfono y solicita ayuda desde MYD indicando el modelo y la versión de Android.

Samsung: instalar desde Mis archivos
  1. Abre Mis archivos > Descargas y toca MYD.apk.
  2. Si aparece “Por seguridad, tu teléfono no tiene permiso para instalar aplicaciones desconocidas”, abre Ajustes desde ese aviso y permite esta fuente para Mis archivos o el navegador que usaste.
  3. Regresa al instalador y confirma. Después, desactiva de nuevo el permiso para esa fuente.
Otros teléfonos Android
  1. Abre Descargas o la aplicación Archivos y toca MYD.apk.
  2. Si el sistema pide permiso, busca en Ajustes “Instalar aplicaciones desconocidas” y permite temporalmente la fuente que descargó el APK.
  3. Instala MYD y luego desactiva ese permiso.
