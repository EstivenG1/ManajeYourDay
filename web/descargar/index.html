Instalación general
  1. Descarga el APK desde el botón oficial de esta página.
  2. Abre la notificación de descarga o busca MYD.apk en Descargas.
  3. Si Android pide permiso, permite temporalmente que la aplicación que descargó el archivo (Chrome, el navegador o Archivos) instale aplicaciones desconocidas.
  4. Vuelve al instalador, toca Instalar y espera a que termine. Después puedes desactivar el permiso del paso anterior.

Pasos según la marca de tu teléfono

En todos los teléfonos el proceso es el mismo; aquí indicamos dónde encontrar el APK y el permiso en cada marca. Los nombres pueden variar un poco según el modelo y la versión de Android.

Huawei / Honor
  1. Descarga MYD desde el botón de esta página. Abre la notificación o entra a Archivos > Descargas y toca MYD.apk.
  2. Si aparece un permiso, toca Ajustes y habilita Permitir instalaciones de aplicaciones para el navegador o Archivos que abrió el APK. Si no encuentras el ajuste, busca “instalar aplicaciones externas” en Ajustes.
  3. Regresa al instalador, confirma Instalar y, al terminar, desactiva el permiso para esa fuente.
Redmi / Xiaomi / POCO
  1. Descarga MYD desde esta página. Abre la notificación o entra a Administrador de archivos > Descargas y toca MYD.apk.
  2. Si Android pide permiso, toca Ajustes y permite instalar aplicaciones para el navegador o Administrador de archivos que usaste. Si hace falta, busca “instalar aplicaciones desconocidas” en Ajustes.
  3. Regresa, toca Instalar y espera a que finalice. Después desactiva el permiso que habilitaste.
Samsung
  1. Descarga MYD desde esta página. Abre la notificación o entra a Mis archivos > Descargas y toca MYD.apk.
  2. Si aparece un permiso, toca Ajustes y activa Permitir desde esta fuente para Mis archivos o el navegador que abrió el APK.
  3. Regresa al instalador, toca Instalar y, al terminar, desactiva el permiso para esa fuente.
Motorola, OPPO, Pixel y otras marcas Android
  1. Descarga MYD desde esta página. Abre la notificación o entra a Archivos > Descargas y toca MYD.apk.
  2. Si Android pide permiso, toca Ajustes y habilita temporalmente Permitir desde esta fuente para el navegador o Archivos que usaste.
  3. Regresa, toca Instalar y, cuando termine, desactiva ese permiso.
Si aparece un aviso

Instala solo el APK descargado desde esta página oficial, A su vez tendras que darle permisos al navegador para instalar aplicaciones desconocidas

En caso de que Play Protect indique que la aplicación es dañina, deberas dirigirte a Play Store, Click a tu foto, Click a "Play Protect" y desactivarlo y volver a iniciar la descarga (Luego podras volverlo a activar)
